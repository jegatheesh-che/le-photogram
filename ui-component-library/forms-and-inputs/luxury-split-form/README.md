# Luxury Split Registration & Inquiry Form

A high-converting 2-column split form inspired by architectural editorial monographs, pairing a sticky full-bleed golden hour photo on the left with a registration form card on the right.

---

## Architectural Features

1. **Left Half (Media)**: Sticky photographic estate view with glassmorphic badge (`PRIVATE CALENDAR • 2026/27`).
2. **Right Half (Form)**:
   - Minimalist back button and clean title.
   - Refined 14px rounded input borders with subtle focus glow.
   - Native HTML5 date picker trigger (`showPicker()`) with automated minimum date enforcement.
   - Full-width pill submit button with asynchronous transmission feedback.
   - Elegant confirmation success banner on submission.
