# Refined Form Controls & Field Groups

A suite of modular atomic form inputs designed with soft 14px border radii, subtle focus elevation rings, and interactive pill toggle chips.

---

## Elements

1. **Text & Number Input (`.ref-input`)**: Crisp 1px `#E5E5E5` border with transition to solid black border and 3px ambient shadow ring on `:focus`.
2. **Custom Select Dropdown (`.ref-select`)**: Custom inline SVG chevron arrow with standard native accessibility.
3. **Selectable Pill Chips (`.ref-pill-chip`)**: Stylized radio/checkbox chips that invert to `#111111` with white text when selected.
4. **Resizable Textarea (`.ref-textarea`)**: Clean multiline field matching single-line inputs.
