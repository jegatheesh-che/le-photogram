# Cinematic Video Background Hero Section

A full-viewport editorial hero section with autoplaying background video, dark gradient scrim, centered white logo wordmark, tracking tagline, and pulsing scroll indicator.

---

## Visual Characteristics

- **Layout**: Fullscreen (`100vh`, `min-height: 640px`) centered flex layout.
- **Media**: Autoplaying background video with fallback poster image.
- **Scroll Cue**: Minimalist animated hairline pulse directing users downward.
- **Micro-Interaction**: Mouse-tracking 3D depth effect separating video layer from center wordmark.
