# Services Floating Plaque Hero

An editorial homage to Japanese architectural book spreads (Homestory style), showcasing an ivory plaque floating directly above a moody background photo with studio handle, miniature inset artwork, and dual-line serif headline.

---

## Visual Characteristics

- **Plaque Surface**: Warm Porcelain `#FAF8F5` card with 0px geometry and deep ambient drop shadow (`0 24px 60px rgba(0, 0, 0, 0.22)`).
- **Typography**: Stacked 76px serif headline, Italian italic subtext, and tracking uppercase handle tag (`@LEPHOTOGRAM.STUDIO`).
- **Responsive**: Max-width dynamically adapts on viewport widths down to 320px with clamp-based paddings.
