# Editorial Buttons & Links

Brutalist architectural action buttons and editorial text links adhering to the 0px border-radius standard.

---

## Variations

1. **Brutalist Outline Button (`.btn-pill`)**: Transparent background with 1px black border. Inverts to solid `#141414` on hover with `-2px` vertical lift.
2. **Signature Crimson Primary Button (`.btn-pill-dark`)**: Solid signature crimson (`#800A19`) background for primary high-priority calls to action. Inverts to black on hover.
3. **Warm Ivory Neutral Button (`.btn-pill-warm`)**: Soft ivory backing (`#F7F5EE`) with hairline border for secondary actions.
4. **Editorial Arrow Link (`.editorial-hover-link`)**: Tracked uppercase typography with trailing SVG arrow that expands from 8px to 13px gap on hover while turning crimson.
