# Section Header Pattern

The studio's standard section header hierarchy combining a hairline-bordered metadata eyebrow row with signature crimson category tags, gray index numbers, and high-contrast display serif headlines.

---

## Visual Characteristics

- **Eyebrow Row**: Clean flex layout with `1px solid var(--color-border)` bottom line.
- **Eyebrow Tag**: Signature luxury crimson (`#800A19`) with `2.2px` letter spacing.
- **Counter**: Faint ink gray (`#777777`) with `1.5px` letter spacing.
- **Headline**: 56px Italiana display serif with `-0.48px` tight tracking.
