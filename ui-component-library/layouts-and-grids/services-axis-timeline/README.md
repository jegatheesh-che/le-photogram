# Keijo Offset Axis Timeline

A luxury editorial timeline layout featuring a continuous vertical hairline spine with alternating text columns and overlapping color block / photograph compositions.

---

## Architectural Composition

- **Vertical Axis Spine**: `1px solid rgba(20, 20, 20, 0.16)` centered across the page height.
- **Alternating Cadence**:
  - **Odd Rows**: Right-aligned service description text on the left, paired with an offset Terracotta (`#8C3B24`) accent block and floating photograph on the right.
  - **Even Rows**: Deep Forest (`#23382C`) accent block and photograph on the left, paired with left-aligned service text on the right.
- **Service Inclusions**: Structured bullet points for coverage hours, album deliverables, and digital vaults.
- **Responsive**: Seamlessly shifts to a stacked single-column card layout on screens `<= 860px` with the central axis line hidden.
