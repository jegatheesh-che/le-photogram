# Editorial Triptych 3-Column Board

The studio's flagship architectural triptych board featuring a 3-column asymmetric layout with an architectural crimson offset background box, stacked photography frames, and editorial narrative typography.

---

## Architectural Composition

1. **Left Column**: High-impact editorial title with italic ampersand (`ART CRAFTED & WITH LOVE`), mission subhead, narrative description, and EST studio timeline.
2. **Center Column**: Architectural Crimson Blaze (`#800A19`) underlay block (`78%` width) offset behind a floating hero photograph with ambient drop shadow.
3. **Right Column**: Dual stacked photo frames flanking an editorial story card and dynamic arrow link.
