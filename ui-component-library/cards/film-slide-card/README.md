# Cinematic Film Slide Reel Card

A video-first card designed for horizontal carousels or editorial grids, presenting autoplaying cinematic motion picture reels with an ambient gradient scrim and anchored action button.

---

## Visual Characteristics

- **Dimensions**: Fixed 380px width & 480px height (responsive down to 380px height on mobile).
- **Video Handling**: Seamless autoplay, loop, muted, playsinline video background with fallback poster.
- **Micro-Interaction**: Gentle scale on hover (`scale(1.05)`) with hover scrim deepening.
