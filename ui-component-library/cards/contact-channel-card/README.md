# Contact Communication Channel Cards

Interactive contact channel list items with floating circular icon badges that invert to solid signature crimson on hover and translate slightly to the right.

---

## Visual Characteristics

- **Icon Circle**: 48px circle with hairline border and soft ambient shadow.
- **Hover Micro-Interaction**:
  - Circle scales to `1.07` with background inverting to Crimson Blaze (`#800A19`) and icon turning white.
  - Overall row slides `6px` rightward (`translateX(6px)`).
  - Text highlights in crimson.
