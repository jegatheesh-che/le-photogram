# Cinematic Floating Editorial Card

A glassmorphic photo card featuring a translucent white backdrop (`rgba(255, 255, 255, 0.94)` with `blur(20px)`), 4:5 vertical photo ratio, uppercase location label, coordinates caption, and an interactive Crimson glow on hover.

---

## Visual Characteristics

- **Card Styling**: Thin 10px white border frame around photo, dual-layer ambient shadow, and sharp 0px corners.
- **Hover Micro-Interaction**: `-8px` vertical elevation lift with `scale(1.03)` and Crimson Blaze glow (`0 0 30px rgba(128, 10, 25, 0.2)`).
- **Parallax Application**: Can be placed over full-bleed parallax break sections or layered into hero compositions.
