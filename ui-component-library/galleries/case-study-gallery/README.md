# Case Study Editorial Gallery

An alternating 2-column and full-width image grid designed for project case studies and fine art editorial wedding spreads.

---

## Architectural Composition

- **Alternating Cadence**:
  - Full-width hero spreads (`.span-full`, 600px height) spanning across both columns for grand establishing landscape shots.
  - Paired 2-column image cells (480px height) for complementary portrait/detail shots.
- **Parallax Compatible**: Supports `.parallax-frame` container and `.parallax-img` classes for vertical scroll scrub.
- **Responsive**: Downscales to a clean single-column story layout on screens `<= 860px`.
