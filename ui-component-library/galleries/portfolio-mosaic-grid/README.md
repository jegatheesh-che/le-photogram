# Portfolio Masonry Mosaic Grid

A high-performance CSS column-count multi-column masonry mosaic grid that cleanly displays photography collections across varying aspect ratios without layout shift.

---

## Visual Characteristics

- **Layout**: Native CSS `column-count: 3` with `break-inside: avoid` card containers.
- **Micro-Interaction**: Hover elevation `-3px` with inner image zoom to `1.05`.
- **Filtering Ready**: Includes `data-category` attributes on each item for instant compatibility with category filter bars.
- **Lightbox Ready**: Styled with `cursor: zoom-in` for integration with lightbox modals.
