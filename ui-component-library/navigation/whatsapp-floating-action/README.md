# Floating Round WhatsApp Action Button

A tactile, fixed floating action button for direct client messaging on WhatsApp with custom SVG branding, hover elevation, and an expanding tooltip badge.

---

## Features

- **Styling**: WhatsApp Official Green (`#25D366`), 56px circular geometry with dual-layer soft elevation shadow.
- **Hover Micro-Interaction**: Scale lift to `1.08` with `-3px` elevation and tooltip pill expansion ("Chat with Studio").
- **Responsive**: Compacts to 50px on screens `<= 540px` and hides text tooltip for touch ergonomical optimization.
