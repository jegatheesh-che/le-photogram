# /ui-task — Master UI Design & Anti-Slop Execution Directive

When `/ui-task` is invoked, execute UI design and frontend development following the unified **UI-Taste** system:

1. **Anti-Slop:** Forbid generic AI gradients, cookie-cutter cards, and robotic copy.
2. **Impeccable Craft:** Strict modular type scales, optical alignment, and hierarchical corner radii.
3. **Curated Taste:** Warm ambient glows, 1.5px subtle border strokes, bespoke color palettes.
4. **Motion Physics (Emil Kowalski):** Fast spring transitions, tactile `active:scale-95` responses, smooth bottom sheets.
5. **Vercel Guidelines:** Ergonomic touch targets (`>=44px`), accessibility contrast, zero dead-end empty states.
