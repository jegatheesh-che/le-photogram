## Core Directives for Any UI Task:
1. **Never generate AI-slop UI:** No generic purple/blue gradients on black, no cookie-cutter 3-card features, no unstyled HTML elements, and no robotic placeholder text.
2. **Typography & Layout Hierarchy:** Always use intentional modular type scales with optical letter-spacing (`tracking-tight` on headlines, `tracking-wider` on uppercase tags).
3. **Corner Radii Hierarchy:** Containers: 24px–32px, Cards: 16px–20px, Inputs/Buttons: 12px–14px, Badges: 9999px.
4. **Borders & Elevation:** Use `1.5px` subtle semi-transparent borders with soft ambient radial blur glows over muddy drop shadows.
5. **Tactile Interaction (Emil Kowalski standard):** Add `active:scale-95` on all touchable elements with snappy 150ms–250ms spring transitions.
6. **Zero Dead Ends:** Every empty state must have a direct 1-tap call to action.
